# 04 — Ending a Session and Reviewing Records

**What to build:** Let the signed-in VA end the active Session and see its saved date, start time, and end time in a table below the Session controls.

**Blocked by:** 03.

**Status:** done

- [x] The VA can end the active Session with one action.
- [x] The end time is saved to the VA's Time record.
- [x] The completed record shows its date, start time, and end time in the VA's local time zone.
- [x] Completed records appear in a table below the Session controls and remain visible after refreshing or logging in again.
- [x] A different account cannot read or change the record.
- [x] Works on the live URL.
